# Curso IA

## Descripción
Repositorio oficial del curso de Inteligencia Artificial, que incluye ejemplos prácticos y el código de la plataforma web.

## Tecnologías
- **Frontend:** Next.js, React
- **Backend/Procesamiento:** Python (para los ejemplos del curso)
- **Gestión del Proyecto:** Spec-Driven Development (carpetas `.specify` y `specs/`)

## Configuración Rápida (Instalación)
1. Clona el repositorio: `git clone https://github.com/Kratos2210/cursoIA.git`
2. Instala dependencias del frontend: `cd web && npm install`
3. ... (más pasos específicos)

## Estructura del Proyecto
- `web/`: Código fuente de la plataforma web del curso.
- `curso_ejemplos/`: Notebooks y scripts de los ejemplos del curso.
- `specs/`: Documentación de especificaciones técnicas.

## Motivación
Este proyecto nace para proporcionar un entorno educativo completo y reproducible para el aprendizaje de IA, integrando teoría y práctica.

## Limitaciones
- Los ejemplos en `curso_ejemplos/` requieren claves de API para funcionar correctamente.

## Cómo Contribuir
1. Haz un fork del proyecto.
2. Crea una rama con tu funcionalidad (`git checkout -b feature/nueva-funcionalidad`).
3. Haz commit de tus cambios y abre un Pull Request hacia la rama `main`.
